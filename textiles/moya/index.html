About MoYa

Version Release Date: 27 April 2026

MoYa ("Mosaic Yarncraft") is an application developed by Ari Rapkin Blenkhorn (ari@acm.org ) to aid yarn-crafters who want to design patterns which can be used for mosaic knitting/crochet/etc. Mosaic crafting is worked in two contrasting colors of yarn, using only one color per row, alternating rows. A stitch which is the wrong color for a row is permitted only if the stitches above and below match it, as it is worked by creating a long stitch which connects those two stitches.

MoYa is a work in progress, under active development. Feedback is encouraged!

Features:
  • Set the size of your chart in stitches and rows, for a chart that can be used for any craft. Or set it in physical inches based on your personal row/stitch gauge in your chosen craft, and display with non-square stiches. Zoom and pan to see your chart easily.
  • To create your design, you can ...
    -- Click to toggle stitches. Work one stitch at a time, or use a larger square "brush".
    -- Create symmetric designs or mosaic-in-the-round by mirroring stitches from one drawing area to the rest of the image.
    -- Import an existing bitmap as your chart, then modify it.
    -- Import a background reference image, and draw over the reference image to create your chart.
    -- Turn a reference image into a chart in one step with automatic algorithms such as threshholding and dithering.
  • Check whether your chart is valid for mosaic yarn-crafting. Visual feedback updates as you modify the design.
  • Display your chart in black and white (the default) or set your palette to reflect the actual yarns being used.
  • Save your chart as a simple pixel map. Or add row and stitch numbers, long-stitch markers, and row-color indicators, and save as image or PDF.
