Welcome to MoYa

Start a chart one of three ways:

  • Blank: set the size in Chart Size/Gauge, or draw on this one
  • Existing chart: drop an image file here, or load it in Load/Save
  • Picture: load a Reference Image in Load/Save, then trace over it or convert it with Image Processing

Then:

  • Draw: pick a Mode (Toggle, A, B) and click or drag; the Draw menu has brush, symmetry, and colors
  • Check: press V to outline stitches that can't be worked in mosaic
  • Save: as an image or PDF in Load/Save

Open the anytime with U or the 📖 button in the sidebar; ? lists all shortcuts. Press Ctrl+Z to undo.

User's Guide

×

A mosaic chart has two colors, A and B. Each row is worked in one color, alternating A and B from the first (bottom) row up. A stitch of the other color is a long stitch from the row below, so it's only possible where the stitches above and below it are that color too.

1. Start a chart

  • From scratch: open Chart Size/Gauge, set the width and height in stitches and rows (or in inches, from your gauge), and click Create Blank Chart. The chart starts all Color A.
  • From an existing chart: drop an image file onto the chart area, or choose it under Load/Save → Chart / Drawing Layer. Each pixel becomes one stitch, so a chart saved with Save Raw Image loads back exactly.
  • From a picture: choose it under Load/Save → Reference Image. MoYa makes a blank chart the same size and switches the View to Trace Mode, showing your chart over the picture. Set the size you want in Chart Size/Gauge and click Resize All Layers. Then either draw over the picture, or open Image Processing + Validation and click Threshold (light areas become A, dark areas B) or Dither (keeps shading as a pattern of dots).

2. Draw

  • Pick a Mode in the toolbar. Toggle (X) flips a clicked stitch between A and B; a drag paints the color the first stitch flipped to. A (A) and B (B) paint that color; hold Alt to paint the other one.
  • The Draw menu sets the brush size ([ and ]), the display colors of A and B, and fills the whole chart with A or B.
  • Symmetry (also in the Draw menu) copies what you draw across the chart. Mirror L/R and Mirror T/B reflect it. 4x and 8x turn it into a rotationally symmetric design that is worked in rows; validation checks the whole chart. 4x In-The-Round and 8x In-The-Round are for work in the round, where every wedge is worked the same way up, so only the drawing wedge is validated. The 4x and 8x modes need a square chart.
  • The bar at the bottom of the chart shows what a click or drag will do right now.
  • Ctrl+Z undoes and Ctrl+Y redoes any change.

3. Move around

  • The mouse wheel (or I / O) zooms; hold Space and drag to pan; F fits the chart to the window. ? lists every shortcut.
  • The View list switches between the chart, the reference picture, and Trace Mode (T).
  • The Display menu turns on grid lines, rulers, non-square stitches (from your gauge), and chart markings.

4. Check that it can be worked

  • Press V (or Validate Chart in Image Processing + Validation). Stitches that can't be worked in mosaic are outlined in red, and the counts appear under Information. It updates as you draw.
  • First Row Color A sets which color the first row is worked in.
  • Toggle All Invalid Stitches flips every red stitch to its row's color.
  • Chart markings in the Display menu mark the anchors of each long stitch, for knitting (up) or crochet (down).

5. Save

  • In Load/Save: Save Raw Image (one pixel per stitch), Save Chart As Image, or Save Chart As PDF for printing, with rulers and markings.
  • MoYa starts fresh each time it opens. To keep working on a chart later, save it with Save Raw Image and load it again as an existing chart.

About MoYa

×
🧶

App Version: 1.0

Version Release Date: 27 April 2026

MoYa ("Mosaic Yarncraft") is an application developed by Ari Rapkin Blenkhorn (ari@acm.org) to aid yarn-crafters who want to design patterns which can be used for mosaic knitting/crochet/etc. Mosaic crafting is worked in two contrasting colors of yarn, using only one color per row, alternating rows. A stitch which is the wrong color for a row is permitted only if the stitches above and below match it, as it is worked by creating a long stitch which connects those two stitches.

MoYa is a work in progress, under active development. Feedback is encouraged! New to MoYa? .

Features:
  • Set the size of your chart in stitches and rows, for a chart that can be used for any craft. Or set it in physical inches based on your personal row/stitch gauge in your chosen craft, and display with non-square stitches. Zoom and pan to see your chart easily.
  • Start your design in any of three ways:
    • Draw it from scratch on a blank chart.
    • Load an existing chart image, then modify it.
    • Load a reference picture, then trace over it, or turn it into a chart in one step with thresholding or dithering.
  • Draw by clicking or dragging: toggle stitches between Color A and Color B, or paint either color, one stitch at a time or with a larger square brush. Undo and redo any change.
  • Create symmetric designs: mirror left/right or top/bottom, 4x or 8x rotational designs worked in rows, or 4x or 8x mosaic-in-the-round, copying what you draw in one area to the rest of the chart.
  • Check whether your chart is valid for mosaic yarn-crafting. Invalid stitches are outlined as you draw, and can be fixed in one step.
  • Display your chart in black and white (the default) or set your palette to reflect the actual yarns being used.
  • Save your chart as a simple pixel map. Or add row and stitch numbers, long-stitch markers, and row-color indicators, and save as image or PDF.
